# Frozen synthetic pilot evidence

Checkpoint: 2026-11-11. Source B run: `artifacts/b/runs/pilot-rbq2l5l9`.

These files make the progress presentation shareable without distributing the ignored `artifacts/` directory. They contain synthetic fixture observations only. `scan-run.json` records the container paths, source/rule hashes, tool commands/versions, validity and installed Python packages. Those container paths are provenance, not portable host paths.

`report.json` is a copy of `report.corrected.json`, regenerated by the dependency-free harness locally after correcting the per-tool aggregation bug. The original container-generated `report.json` is preserved in the source run, but its densities aggregate tools incorrectly and must not be used. Future Docker runs use the fixed implementation. No review labels or candidate counts were changed to prepare this bundle.

Other B files were copied from the completed Docker run. `a-pilot-scores.json` is copied from A's completed Docker scoring output. All five review entries remain `unreviewed`; the examples are not audited real-project vulnerabilities. Raw scanner outputs remain in the original run's `scans/` directory; this is a compact presentation extract, not a complete archival experiment bundle.

`manifest.json` records the source run, synthetic status and SHA-256 checksums of the extracted data files. Do not modify this snapshot when reviewing new runs; create a new dated evidence bundle instead. A's benchmark profile, related-engine caveat and B's synthetic limitations are explained in the presentation.
